# Mohammed Sowan — Portfolio

Static personal site (HTML, CSS, vanilla JS). No build step.

## Run locally

```bash
python -m http.server 5500
```

Then open http://localhost:5500.

## Deploy

Hosted on GitHub Pages from the `main` branch of `Mo-Sowan/Mo-Sowan.github.io`.
Push to `main` and the site updates at https://mo-sowan.github.io within a minute or two.

When changing `style.css` or `script.js`, bump the `?v=` query in `index.html` so browsers fetch the new file.

## Editing content

All text lives in `index.html`. Search for `[TODO` to find placeholders that still need real content.
